\# Anti-Nether-Roof



A simple Minecraft plugin that keeps players off the Nether roof by detecting players above Y=127 and applying a configurable punishment.



\## Features



\- Detects players accessing the Nether roof

\- Configurable punishments:

&#x20; - Kill

&#x20; - Kick

&#x20; - Teleport

&#x20; - Ban

\- Bypass permission for trusted players

\- Reload configuration without restarting



\## Commands



/antinetherroof reload - Reloads the plugin configuration



\## Permissions



antinetherroof.bypass - Allows players to bypass Nether roof detection



antinetherroof.reload - Allows players to reload the configuration
